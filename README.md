## Turn these into Power BI / Tableau dashboards
Each `outputs/*.csv` is dashboard-ready. In Power BI: Get Data > Text/CSV > load; build 1 KPI row (cards), 2 trend/bar visuals, 1 slicer-driven drill-down per project; publish to Power BI Service (or Tableau Public) and link it in each README.
